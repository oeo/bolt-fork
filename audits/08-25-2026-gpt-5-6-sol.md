# Audit: bolt

## Verdict

Overall maturity: pre-alpha prototype.

Release decision: blocked.

Requested-feature decision: blocked. Consensus, authorization, persistence, networking, and release gates remain incomplete.

## Critical Findings

```text
c1  src/core/transaction.ts:135, src/crypto/signature.ts:116  critical: signature verifies payload but never proves public key owns `from`; attacker can sign spending from any funded address. Bind canonical public key-derived address to sender and domain-separate signatures by chain ID.
c2  src/core/block.ts:254-309, src/core/blockchain.ts:194-240  critical: only first transaction is checked as coinbase; additional coinbase transactions pass validation and mint unlimited funds. Require exactly one coinbase at index zero.
c3  src/core/blockchain.ts:169-178  critical: account state, transactions, block, tip, and cumulative work commit separately; failure leaves partial consensus state. Create one atomic block transition at storage boundary.
c4  src/core/blockchain.ts:637-982  critical: reorganization does not remove displaced blocks/indexes, clear obsolete accounts, reset cumulative work, or recover atomically. Replace reorganization with a reversible, crash-safe canonical transition.
c5  src/core/blockchain.ts:101-178  critical: block acceptance lacks single-writer serialization; concurrent miners demonstrably add two blocks at same height and apply both state transitions. Serialize block acceptance.
c6  src/storage/lmdb-manager.ts:111  critical: async LMDB transaction callback does not roll back writes after failure; audit probe observed persisted data after callback threw. Implement rollback semantics at storage boundary.
c7  src/types.ts:34, src/storage/adapter.ts:7, src/storage/lmdb-adapter.ts:16  critical: two incompatible storage contracts exist; default LMDB adapter lacks 18 required methods and fails first persisted mempool transaction. Consolidate storage contract and make LMDB satisfy it.
c8  src/network/connection-manager.ts:204-250, src/network/protocol.ts:256-284  critical: peer-controlled frame lengths have no cap, buffering is quadratic, and short version payloads can throw outside peer isolation. Bound frames and isolate malformed peer input.
c9  package.json:25  critical: deprecated IPFS dependency chain includes critical `protobufjs` arbitrary-code-execution advisory. Remove or replace vulnerable dependency chain.
```

## Required Gates

1. Fix sender ownership and exactly-one-coinbase rules.
2. Consolidate storage contract and implement atomic block and state commits.
3. Replace reorganization with reversible, crash-safe canonical transition.
4. Add state roots and deterministic state reconstruction.
5. Serialize block acceptance and test concurrent competing blocks.
6. Establish chain-specific authenticated networking with bounded messages.
7. Restore working transaction relay and cumulative-work synchronization.
8. Make LMDB pass the same contract suite as memory storage.
9. Enable real two-node Bats tests covering restart, relay, partition, reorganization, and malformed peers.
10. Reach clean typecheck, dependency audit, reproducible builds, and mandatory CI.

Smart contracts should wait until gate 4. Private transactions should wait until all gates pass, then build commitments, nullifiers, proof verification, and amount conservation against committed canonical state.
